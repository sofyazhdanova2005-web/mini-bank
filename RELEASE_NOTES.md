Первая версия прототипа «Мини-банк».

**Файлы релиза**

- `MiniBank-Setup-*.exe` — установщик для Windows (Inno Setup)
- `er-diagram.drawio` — ER-диаграмма базы данных, открывается в draw.io
- `er-diagram.png` — та же диаграмма картинкой
- `schema.sql` — SQL-скрипт создания базы данных (SQLite)

**Что умеет программа:** регистрация клиентов, открытие счетов, пополнение и снятие, переводы между счетами, история операций.
